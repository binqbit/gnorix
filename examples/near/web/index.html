PROTOTYPE

This demo shows how biometrics can sign an action. Its cryptographic security is still experimental and is not guaranteed.

FROM FINGERPRINT TO APPROVAL

How it works

  1. Find the useful details

    Gnorix finds distinctive points in a fingerprint, such as where a line ends or splits, and rates how clearly each one appears.

  2. Prepare many ways to sign

    It combines these points in different groups, giving clearer details more weight. Each chosen combination produces a signing key. One public ID represents this set of prepared keys.

  3. Use a smaller sample

    A fresh scan can contain just part of the fingerprint. Gnorix tries combinations from that sample, allowing for small shifts, until it recovers a registered key. If it cannot find one, the attempt does not produce a signature.

  4. Approve the exact transfer

    The recovered key signs the chosen recipient and amount. NEAR checks the signature and verifies that the key belongs to the registered set before moving the test tokens.

This shared demo uses test fingerprints and test tokens on a private local chain.
